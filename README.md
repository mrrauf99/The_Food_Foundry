# Food Foundry

Food Foundry is a Chicago-based founder community and accelerator for startups
building in food and foodservice. The site supports the public program, startup
showcase, and contact flows for the organization, which is backed by Relish
Works and Gordon Food Service.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Radix UI
- Zod
- nuqs

## Features

- Program and company overview pages
- Startup showcase with filtering and search
- Contact and newsletter forms with validation
- Responsive navigation and shared site layout
- SEO metadata, sitemap, robots, and Open Graph support
- Accessible UI with keyboard-friendly components and reduced-motion support

## Company

Food Foundry is focused on supporting founders in the food ecosystem through
community, programming, and visibility. The site presents the organization’s
mission, startup portfolio, and program information in a clean marketing format.

## Local Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the development server
- `npm run build` creates a production build
- `npm start` serves the production build
- `npm run lint` runs ESLint
